## Efficiency

- Task embeddings per chat turn: **1** (before: 2).
- Small talk: **0** retrievals.

## Metric definitions

- **Accuracy** — share of all queries handled correctly: an answerable query retrieved at least one gold memory, or a no-answer query retrieved nothing.
- **Hit rate** — answerable queries where at least one gold memory was retrieved.
- **Recall** — share of each query's gold memories retrieved.
- **Precision** — share of retrieved memories that were gold (queries that retrieved nothing are excluded).
- **MRR** — 1 / rank of the first gold memory (0 if none).
- **Noise rejection** — no-answer queries for which nothing was injected.
- **Irrelevant / query** — non-gold memories put into the prompt, averaged over all queries.

> ⚠️ Run with the hash embedder: it only matches identical words, so paraphrased questions score poorly. Run `python -m evaluation.retrieval_eval` with MiniLM installed for representative numbers.
